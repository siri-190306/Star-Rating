# ⭐ Star Rating Widget

## 📌 About the Project

The Star Rating Widget is a simple and interactive web development project created as part of Day 19 of my Web Development Track.

It allows users to select a rating from 1 to 5 stars and see an instant response.

## ✨ Features

- Five clickable stars
- Hover preview effect
- Selected rating display
- Personalized rating messages
- Reset rating button
- Responsive and colorful design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

star-rating-widget/
│
├── index.html
├── style.css
├── script.js
└── README.md

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure all three files are in the same folder.
4. Open `index.html` in your browser.
5. Hover over the stars and click to select your rating.
